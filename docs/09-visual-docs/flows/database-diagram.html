Flujograma 04 · Modelo de Datos Relacional

Modelo de Datos: MariaDB (GLPI) + PostgreSQL (Sistema Propio)

Diagrama entidad-relación de las 9 tablas nativas de GLPI y las 4 tablas exclusivas del sistema propio.

Versión: 1.0
Fecha: 2026-10-14
Motor GLPI: MariaDB 11.4 (Base glpi)
Motor Propio: PostgreSQL 16 (Base glpi_ticket_manager)
Principio de Integridad Cross-Database (ADR-012): Las claves foráneas entre bases de datos no existen a nivel físico de motor relacional. Los campos user_id y ticket_id en PostgreSQL representan referencias lógicas a glpi_users.id y glpi_tickets.id en MariaDB. No hay ETL ni replicación redundante de datos.

Nota técnica de persistencia (ADR-012): Las tablas del sistema propio usan BIGINT GENERATED ALWAYS AS IDENTITY para PKs auto-incrementales (audit_log.id). No se usa SERIAL/BIGSERIAL (legacy, no estándar SQL). Asimismo, user_preferences.user_id se define como INT para garantizar paridad exacta de tipos con glpi_users.id, evitando conversiones implícitas en cruces lógicos.
